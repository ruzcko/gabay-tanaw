## What it does

Pick a landing site, or any point on the Moon, and a date. Tanaw gives a Go or No-go call,
the hours of sunlight and of Earth in view, rise and set times, and the site's skyline
with the Sun's and Earth's paths over it. Sites can be compared, viewed in 3D, and
searched by sunlight, Earth visibility and terrain.

## How it's built

Skylines come from NASA LOLA terrain, Sun and Earth positions from NASA/JPL Horizons.
Python in [`science/`](science/) precomputes the forecasts into static JSON in
[`app/data/`](app/data/); the site is plain HTML, CSS and JavaScript with three.js.
Every source and licence is in [SOURCES.md](SOURCES.md).

and the typemark. The idea, the design direction and the data choices are ours, and we
reviewed every AI-assisted change; those commits name the tool in a `Co-Authored-By`
line. No images, video or audio in this project were generated by AI.
